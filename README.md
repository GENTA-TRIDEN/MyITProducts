# 最近1年で調べて試したIT関連の取り組みまとめ

直近1年間で、開発効率の向上やイベント運営のシステム化を目的に、自身で調査し実践した3つの取り組みについて記載する。

## 1. Google Apps Script (GAS) を活用した手描き図形データ収集Webアプリの開発
* **きっかけ:** 形状認識AIのトレーニング用に、256x256ピクセルの手描きシェイプ画像を効率よく収集し、Googleドライブへ直接蓄積する仕組みが欲しかったため。
* **どこまで試したか:** 
  ブラウザ上の描画キャンバスからJavaScriptで画像データを取得し、バックエンドのGAS経由で指定のGoogleドライブフォルダへ自動保存するパイプラインを構築。
* **効果と課題（客観的視点）:**
  * **効果:** 手作業でのファイル保存やリネーム作業が不要になり、データ収集・整理のステップが大幅に時短された。
  * **課題:** 大量のリクエストを同時に処理する際のGASの実行時間制限（スロットル）や例外処理のハンドリングに注意が必要である。

## 2. 自作分割キーボード「Keyball44」の組み立てとカスタマイズ
* **きっかけ:** 長時間のコーディング作業における手首や肩の負担（エルゴノミクス改善）と、タイピング効率の限界突破を目指したため。
* **どこまで試したか:** 
  基板へのダイオード・スイッチの手ハンダ付け、マイコンのファームウェア書き込み、テンティングスタンドの調整までハードウェア・ファームウェアの両面を自ら構築・調整。
* **効果と課題（客観的視点）:**
  * **効果:** 指の移動量が減り、レイヤーキーを活用することでキーボードから手をほとんど動かさずに操作できるようになり、コーディング時の疲労が軽減された。
  * **課題:** 製作コストと初期のハンダ付け不良などのトラブルシューティングにかかる時間が大きいため、一般的な既製品に比べてハードルが高い。

## 3. 文化祭コーヒースタンド向けタブレットPOSレジ・リアルタイム売上管理システムの構築
* **きっかけ:** 本格的なシングルオリジンコーヒーの提供と、カスタムトッピング、ダイスゲーム「チンチロ」による割引判定をレジ前でスムーズに処理し、集計ミスを防ぎたかったため。
* **どこまで試したか:** 
  タブレット端末で動作するメニュー選択や釣銭計算機能を備えた会計アプリを設計し、Googleスプレッドシートと連携させてリアルタイムでの売上・杯数管理を行う仕組みを構築。さらにチンチロの割引ロジックを精算フローに組み込み、事前の動線・オペレーションシミュレーションを実施。
* **効果と課題（客観的視点）:**
  * **効果:** 暗算や手動での計算ミスがなくなり、ピーク時でもレジの回転率が向上。クラウド上での自動集計により、営業時間中の売上把握や終了後の締め作業が大幅に時短された。
  * **課題:** ネットワーク環境の不安定さによるスプレッドシート同期の遅延や、タブレット端末のバッテリー・電源管理への事前の備えが重要になる。
